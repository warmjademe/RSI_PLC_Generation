# NAS 与华硕当前 100 题历史记录体积

2026-09-18 实测，使用 `du -B1`。下列 GB 按 1,000,000,000 字节计算，是未压缩目录磁盘占用，不是压缩包传输量；运行中目录可能继续变化。

| 主机 | 当前实验 | 大小 GB |
|---|---|---:|
| NAS | 八基线 Qwen | 15.01 |
| NAS | 八基线 DeepSeek 官方 | 16.52 |
| NAS | 八基线 Haiku 4→10 续跑，包含原始历史 | 13.26 |
| 华硕 | 我们的方法及消融 Qwen | 5.10 |
| 华硕 | 我们的方法及消融 DeepSeek 最终合并结果，含链接目标 | 4.16 |
| 华硕 | 我们的方法及消融 Haiku v3 | 3.13 |

NAS 合计约 44.79 GB，华硕约 12.39 GB，总计约 57.18 GB（53.25 GiB）。不额外累计 NAS Haiku 原 4 次目录（约 6.31 GB），其历史已进入续跑目录；也不将华硕 DeepSeek full20 别名和原运行目录整份重复相加。

华硕 DeepSeek 最终目录本体只有约 1.42 GB，但 `arms/NoFeedback`、`NoAssets`、`Neither` 以及相应 tests、源码、数据和评价器均有软链接。`du -L` 计入这些目标后为 4,164,866,048 字节。迁移不能只复制链接本身。初步不跟随链接的主机小计会低估约 2.75 GB。

轻量汇总口径：六组目录的顶层普通文件，加各自 `cost_accounting` 目录，约 82.5 MB；含汇总、部分逐题结果表、配置及逐调用 token 账本，**不包含全部请求响应、运行验证证据和知识快照**。该口径混合文件实际长度与 cost_accounting 目录块占用，仅作同步容量估算。

NAS 的 `tests` 合计约 18.06 GB；`streams` 及 Haiku `extension_learning` 合计约 26.50 GB。这解释了为什么完整复现历史远大于汇总文件。华硕主要体积在各组件组的 `arms`，其中包含模型 wire 请求响应、运行目录和知识数据库，不能全部称为知识快照。

本轮仅统计，没有同步或删除远端数据。压缩率未实测，不承诺压缩后的体积。
